# Components

Reusable Web Components for the Protoboard Explorer site.

## Files

- `detail-layout.scss`: Stylesheet for the detail page layout component using Carbon semantic design tokens and typography mixins.
- `detail-layout.ts`: Implementation of `<pbd-detail-layout>`, providing a dual-view preview (Live Component vs HTML Code) and slots for documentation sections.
- `slot-assigner.scss`: Stylesheet for the slot assigner container component.
- `slot-assigner.ts`: Implementation of `<pbd-slot-assigner>`, a signal-watched face slot assignment widget querying child row selections on demand.
- `slot-row.scss`: Stylesheet for the slot row component using Carbon design tokens and typography mixins.
- `slot-row.ts`: Implementation of `<pbd-slot-row>`, rendering face slot preset selection dropdown and thumbnail previews for an individual slot row.
