# Source Directory

This directory contains the TypeScript source code for the Protoboard library.

## Subdirectories

- [`core/`](./core/): Core infrastructure and Lit Context dependency injection foundation.
- [`pieces/`](./pieces/): Tabletop piece components.
- [`testing/`](./testing/): Test-only entry point and exports for test suites.

## Directory Inventory

- [`index.ts`](./index.ts): Main library entry point exporting `initialize`.
